# IbaJamal-Haircut

This repository contains the landing page for "IbaJamal-Haircut" — a simple, responsive salon booking landing page built with HTML, CSS, and vanilla JavaScript.

## What this is

- A static landing page showcasing services, pricing, and a booking call-to-action.
- Responsive layout, lightweight styles in `styles.css`, and small interactive behavior in `script.js`.

## Run locally

1. Clone the repository and open the project folder.
2. Open `index.html` in your browser (double-click or use a local server).

Optional: serve with a simple HTTP server for better routing and debugging:

```
# Python 3
python -m http.server 8000

# or with Node.js (if you have http-server installed)
npx http-server -c-1
```

Visit `http://localhost:8000` (or the port shown) to view the site.

## Deploy to GitHub Pages

1. Create a GitHub repository and push this project to the `main` branch.
2. In the repository settings > Pages, set the source to the `main` branch and the `/ (root)` folder.
3. Save and visit the published URL shown in the Pages section.
